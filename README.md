# Расписание Аничкова лицея
*Создана полноценная программа для составления расписания, которая вклюяает в себя не только алгоритм создания, но и графический интерфейс*
***
### Что это за Аничков лицей?
Эта школа расположена в сердце города Санкт-Петребурга - рядом с речкой фонтанкой. И как раз в том числе эта река создает большую проблему в создании расписания: учителя могут переходить между Фонтанкой для перехода между корпусами. Эти переходы нужно минимизировать.

### Актуально ли это?
Администрация этого учебного заведения составляло расписание вручную. Но почему она не могла использовать уже созданные программы по его составлению? Во-первых, в нашем мире любое ПО стоит немало денег, во-вторых, интерфейс таких программ всегда перегружен, в-третьих, не все программы учитывают специфику моей школы. 
Создание хорошего расписания важно как для учеников, так и для учителей: первым не надо отвлекаться на ошибки расписания (один кабинет у двух классов, учитель в одно время у двух классов и т.п.), а вторым нужны более комфортные условия работы (меньше окон между уроками, преподавание в приоритетных кабинетах и т.п.)

### Как работает программа?
У нас есть некоторый solver (ядро самой программы), который обеспечивает умный и быстрый перебор вариантов, а наша задача установить только ограничения. Для этого в Python существует внешний модуль от Google- ortools: там задается целевая функция и ограничения для нее. Также нужно указывать время работы программы, так как этот умный перебор не гарантирует наилучшее решение, но чем дольше будет работать программа, тем решение будет оптимальнее. Еще стоит отметить, что сам перебор и работа со всеми входными данными ortools (работа solver) осуществляет на языке программирования c++, что обеспечивает большую скорость работы из-за компилируемости этого языка программирования.
Ядро минимизирует количество переходов между корпусами и окна учителей между уроками, а максимизирует кол-во пар в уроках классов.
**Учитываемые ограничения**:
1.	*Должен выполнятся учебный план*- сколько часов указано в предмете класса, столько уроков и должно быть
2.	*Учитель не может вести два урока одновременно*- совершенно неочевидная вещь, выявленная эмпирическим путем
3.	*Учитель не может вести урок при исключениях*
4.	*Не может быть окон у классов*- не должно допускаться такого, что по сере-дине учебного дня у класса появляется свободный урок/уроки
5.	*Не может быть больше 2-х предметов одной дисциплины*- расписание с 5-ю физиками в один день исключается
6.	*Как минимум 5 уроков в день*- уроки должны распределятся в течении недели в той или иной степени равномерно (Это ограничение используется в програм-ме алгоритма уже)
7.	*Нет первых двух уроков в понедельник*- эти два урока выделены для проведе-ния разговоров о важном
8.	*Жесткие пары для английского*- учителя по английскому в моей школе тре-буют, чтобы у них была обязательно пара + один урок (у всей школы 3 часа английского в неделю)
9.	*Физра в конкретных слотах у классов*- в нашей школе есть бассейн, который требует соблюдения жесткого регламента по времени проведения уроков физ-культуры, поэтому этот урок у каждого класса зафиксирован в конкретных уроках
10.	*Жесткое ограничение на переходы для учителей, не имеющих возможности на переход за 1 перемену*
11.	*Максимум 1 информатика на корпус в один и тот же урок*- на каждый кор-пус у нас по два кабинета информатики, поэтому не хватило бы кабинетов для двух информатик в один момент в одном корпусе 
12.	*Не должно быть разрывов в уроках*- расписание: русский, потом физика, потом опять русский- не допускается
13.	*Если есть внеурочная деятельность, то может быть 8 уроков в день*- помимо этого внеурочная деятельность может быть только первым, либо послед-ним уроком
